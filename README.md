# NOURA MVP v2

Klickbarer, dependency-freier Prototyp für eine Ernährungs-, Supermarkt- und Alltags-App.

## Neu in v2

- Persönliche Gelüste auswählbar: süß, salzig, cremig, knusprig, herzhaft, frisch, scharf, Comfort Food
- Lieblingsessen auswählbar
- Abneigungen auswählbar
- Allergien & Unverträglichkeiten auswählbar
- Ernährungsstil und Ziel auswählbar
- Kochzeit und Haushaltsgröße auswählbar
- Auswahl wird im Home-, Plan- und Tracking-Bereich sichtbar berücksichtigt
- Zyklus, Schlaf, Schritte, Kalorien, Protein und Supermarkt bleiben enthalten

## Start

Einfach `index.html` im Browser öffnen. Für GitHub Pages das Repository hochladen und Pages auf den Root-Ordner des Branches aktivieren.

## Hinweis

Dies ist ein Frontend-MVP mit lokalen Mock-Daten. Echte Supermarktpreise, Login, Apple Health/Health Connect, serverseitige Speicherung, KI-Rezeptgenerierung und medizinische/gesundheitsbezogene Logik benötigen später Backend, APIs, Datenschutzkonzept und echte Integrationen.
